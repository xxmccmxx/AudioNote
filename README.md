## 第 1 页：入职 2 个半月的工作学习收获

标题建议：

**入职 2 个半月的工作学习收获**

副标题可以写：

**在师傅带教和部门培训支持下，逐步完成从认识业务到参与岗位实践的过渡**

### 版式

左侧突出时间：

**2.5个月**

下面放一句总结：

> 完成业务认知、流程熟悉和基础岗位实践

右侧使用一条横向时间轴：

**认识业务 → 熟悉流程 → 跟岗实践 → 复盘沉淀**

每个节点下面写 1～2 条真实内容，例如：

* 认识业务：了解国际订单、物流及仓储中心的基本业务链路
* 熟悉流程：熟悉岗位涉及的系统、单据和关键节点
* 跟岗实践：在师傅带领下参与具体任务
* 复盘沉淀：形成流程笔记、问题清单或操作记录

底部放一个“收获落点”区域，建议写 3～4 条：

* 对部门业务和岗位职责有了整体认识
* 掌握了基础工作流程和操作要求
* 提升了任务执行和跨岗位沟通意识
* 初步形成了记录问题、及时请教、复盘总结的工作习惯

重点是展示“发生了什么变化”，不要只罗列参加过哪些培训。

## 第 2 页：当前工作内容与阶段成果

标题建议：

**当前工作内容与阶段成果**

这一页要回答四个问题：

> 我在做什么？做到什么程度？取得了什么结果？留下了什么产出？

### 推荐版式：四列表格

| 工作模块    | 我的具体工作              | 当前进展             | 阶段产出            |
| ------- | ------------------- | ---------------- | --------------- |
| 业务流程熟悉  | 跟随师傅了解相关业务节点和操作要求   | 已完成基础熟悉，正在加强实际应用 | 流程笔记、岗位学习清单     |
| 日常任务执行  | 参与或负责具体订单、仓储、物流相关事项 | 按要求持续开展          | 系统记录、台账、报表或任务记录 |
| 异常与协同事项 | 参与问题跟进、信息核对和部门协同    | 部分事项已完成闭环        | 问题清单、跟进记录、复盘材料  |

表格中的内容要换成你的真实工作，不要虚构。

### 顶部可以增加 2～3 个真实数据

例如：

* 覆盖工作模块：X 类
* 参与具体任务：X 项
* 形成工作产出：X 份

如果暂时没有准确数字，就不要强行放数据，可以改成：

**当前重点：流程熟悉｜任务执行｜问题跟进**

### 成果表达建议

每项工作尽量采用：

> 动作 + 工作对象 + 结果 + 证据

例如：

> 参与海外订单相关流程跟进，熟悉订单节点衔接，形成个人流程记录。

成果不一定要是大型项目。对校招生来说，培训笔记、流程图、操作清单、报表、问题闭环记录、独立完成的基础任务，都可以作为有效产出。

## 第 3 页：对部门的建议

标题建议：

**基于新人视角的部门建议**

建议不要直接写“加强培训、加强沟通”这类空泛内容，而是采用：

> 观察到的问题 → 建议动作 → 预期效果

### 推荐版式

左侧放一段“我的观察”：

> 入职初期需要同时理解业务流程、系统操作和跨岗位协同。若能将关键任务和典型问题进一步沉淀，新员工可以更快形成完整的业务认识。

右侧放 2 条建议：

| 建议方向      | 建议动作                      | 预期效果              |
| --------- | ------------------------- | ----------------- |
| 新人学习任务清单化 | 按入职阶段整理岗位必学内容、关键流程和实践任务   | 帮助新人明确学习路径，减少遗漏   |
| 异常案例和经验沉淀 | 定期整理订单、仓储、物流协同中的典型问题和处理方式 | 提升新人对异常事项的判断和处理效率 |

底部增加一个“我能做什么”：

> 后续将持续完善个人流程笔记和问题清单，及时复盘工作中的典型事项，并将可复用内容整理成简明资料。

这样既提出了建议，也体现了个人责任感。

## 三页统一设计

* 标题字号：32～36 pt
* 正文字号：18～22 pt
* 页面顶部固定部门名称，右上角放 `01/03、02/03、03/03`
* 页脚统一放：`2026届校招生述职汇报｜姓名｜日期`
* 奇瑞红只用于标题强调、时间轴节点、关键数据和分隔线
* 每页只保留一个核心结论，避免堆满文字
* 尽量使用真实证据，不使用“全面提升、显著增强、赋能成长”等空泛表述

整体上，三页可以形成这样的逻辑：

```text
第1页：我学到了什么
        ↓
第2页：我正在做什么，并留下了什么成果
        ↓
第3页：我观察到什么，还能怎样改进
```
