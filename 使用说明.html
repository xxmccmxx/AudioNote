年度计划调量助手 · 0.1.0 试用版

适用于 Windows 10/11 64位。完整解压后双击 PlanAssistant.exe。程序已包含运行所需组件，公司电脑无需安装 Python、Codex 或求解器，不需要管理员权限，运行中不访问网络。

这是已通过模拟数据和程序测试的首版原型。尚未在你的真实工作簿或公司 WPS 环境中验证。请先体验模拟项目，再用脱敏副本核对导入、公式、透视表及导出结果。

先用模拟数据体验

  1. 点击“载入模拟数据”。示例共36行，全年183,600；甲国-C是超限示例。
  2. 进入“4 调整任务”，目标选“欧盟地区部 / C”，补偿品牌选O，调整量填 -1000。
  3. 点击“生成配平方案”。每阶段时限20秒时，整轮通常最多约一分钟，加上建模时间。
  4. 查看地区品牌汇总、逐行年度汇总、逐月变更明细。未证明分散最优时会明确显示。
  5. 点击“应用本方案并保存项目”，选择项目保存位置。应用前会保存恢复副本。可用“撤销最近一次应用”恢复。

也可以打开随包提供的“模拟项目.plan.json”。模拟项目没有原始Excel，因此可导出变更CSV，不能导出原格式工作簿。

导入实际工作簿

  1. 在“1 数据与列映射”选择 .xlsx 或 .xlsm。旧版 .xls、WPS .et、加密文件请先在WPS中另存为可读取的工作副本。
  2. 选择明细工作表、表头行和明细结束行。范围只能包含完整明细，不得包含小计或汇总行。
  3. 读取表头及样例，逐项确认地区部、国家、国际品牌、业务单元、车型代码、产品线、出口类型、燃油类型、1—12月，以及可选的全年合计列。列号可以变化，不要求W—AH固定不变。
  4. 确认映射并建立基准。空白月份按0读取。关键维度不完整、负数、小数、非法KD值会被指出。
  5. 进入“3 燃油与范围”，填写版本全年总量：T3填2005000，244挑战版填2440000；脱敏样表填其实际总量。

每次重新导入Excel会建立新项目和新基准。连续多天调整，请使用“打开项目”恢复原项目，不要每天重新导入并重设基准。

业务单元限额

按实际业务单元完整名称设置年度上限；名称后缀不决定国际品牌。一项业务单元内可有不同国际品牌，限额约束该业务单元全部行的合计。

设置含义
非负整数年度上限。超过时标红，不允许增加。
0禁止增加。在指定减量范围内允许各行全部清零，锁定项仍然有效。
不限量明确不设业务单元上限；每行60%边界和其他规则仍然有效。
空白 / 未设置标黄，禁止增加，允许在其他规则下减少。

可按Ctrl多选业务单元后统一设置。也可导出限额CSV，在WPS内填写“年度上限”列后另存为UTF-8 CSV再导入。留空表示未设置，“不限量”须写全；业务单元名称必须匹配原表。

每次填写一条任务

指定目标地区部和国际品牌，调整量减少填负数、增加填正数。可进一步指定目标国家或业务单元。补偿品牌选具体品牌时，该品牌在目标地区承担反向补偿；选“自动选择”时，允许程序使用其他品牌。

“允许地区部 / 允许国家”限制所有配平动作，不只限制目标行，需把目标和可配平对象都包括在内。国家、车型代码和月份可锁定。名称须与数据完全一致，多项用英文逗号分隔，锁定月份填1—12。

已超限业务单元仅在明确减量范围内参与减少。目标为增量且已指定补偿品牌时，该地区补偿品牌也属于明确减量范围。自动寻找的其他超限业务单元不会自行被减。

计算规则

  • 公司全年、各地区部、各国际品牌、每个“国际品牌＋产品线”的全年合计守恒。产品线按品牌分别计算。
  • 普通行最终全年量为固定基准的40%—160%，整数取整。业务单元限额为0时允许清零；该例外不会取消锁定和守恒。
  • KD每行1—11月始终为60的倍数或0；12月和CBU为非负整数。不要求不同转移行出口类型一致。
  • 全零基准行不能增加；启动前零月份禁止增加；中间或年底零月份默认禁止增加，可主动放开。
  • 尽量平均分配本次增减量，不拉平最终月度数量。KD粒度、月度可减空间和锁定可能导致分配不完全平均。
  • 支持全公司、地区部、国家三级燃油类型上限。燃油上限为硬限制；若原表已超过燃油上限且无法配平纠正，会报告无可行方案。
  • 先争取完成目标量，再优先消除指定减量范围的超限部分，超过上限的部分优先处理。之后使用软偏好：大行之间适当分散、少动小行、尽量同燃油类型转移、减少无关变动和地区数量。
  • “大行”“适当分散”属于偏好，程序用递增调整成本实现，并非新增硬阈值。解法不唯一，达到时限时可能只有合法方案，尚未证明分散方式最优。
  • 部分完成也必须整套配平。未证明最大量时只称已找到可行量，不能称最大可调量。

项目、预览、应用与导出

生成预览不修改当前计划；应用后更新项目文件。项目保留固定基准、原工作簿、当前计划、限额和历次调整。项目文件旁的 .before-编号.json 为应用前恢复副本，可通过“打开项目”恢复。

未应用的方案可以放弃。导出Excel前须先应用或放弃预览，导出的是当前已应用计划。输出必须使用新文件名和原扩展名，原始Excel保持不变。若导入后原Excel发生人工改动，导出将被阻止，须先核对后重新建项目。

导出按原始工作簿包修改相关数字，保留其他成员、格式、公式和宏；若指定全年合计列，也会更新该列数字或公式缓存。月份中已有公式的单元格会自动锁定；公式缺少缓存值时须先用WPS重新计算并保存。导出后用WPS重新计算全部公式，并刷新数据透视表。复杂图表、外部链接、宏行为尚需在真实文件中确认。

导出工作簿旁会保存调整记录JSON。变更CSV包含完整的原行号、维度、月份、前值、增减和后值；界面明细最多展示前3000个变更。

验证范围

27项程序测试通过，涵盖规则边界、固定基准连续调整、跨三个地区的六步闭环、KD余数、锁定、缺失限额、零限额清零及后续任务、燃油上限；另检查OOXML样例的公式、样式和未修改成员保留。窗口流程已检查应用保存与撤销。3,800行模拟计划全年200.5万，成功完成1万调量；本机运行约40秒，所有硬规则校验通过，分散偏好在时限内未证明最优。运行速度会随电脑、数据结构、限制数量改变。

完整包应保留 _internal 与 solver 文件夹。请将项目保存在你有写入权限的目录。计算核心为HiGHS 1.15.1，来源及许可证见licenses目录。
